# v11 Design Target Feature Map

## Primary architecture
Explorer Select → Full-screen Ocean Expedition → in-game navigation.

The old Adventure Hub and World Map are not part of the child-facing route. Future worlds remain locked only in backend progression data and are not shown to children.

## Game HUD
Explorer profile, level/XP, Adventure Energy, pearls, shells, current mission, region exploration, discoveries, treasure, mastery trial state, contextual discovery caption, and a bottom action dock.

## In-game destinations
Learning, Aquarium, Store, Journal, Explorer Cabin, Knowledge Bank, Mastery Constellation, and Adventure Settings.

## Preserved engines
Adaptive quizzes, question audit, mastery, allowance, remediation, Parent Admin, achievements, saves, offline/PWA support, World 1 exploration gates, and boss/mastery trials.
